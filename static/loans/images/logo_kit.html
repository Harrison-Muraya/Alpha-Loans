Integration Code

Copy-paste ready snippets for every use case in your Django project.

① Navbar (base.html)
<!-- Replace the existing logo section -->
<div class="flex items-center">
  <img
    src="{% static 'images/logo.svg' %}"
    alt="Loan Manager"
    class="h-9 w-auto"
  />
</div>
② Email template
<!-- In password_reset_email.html -->
<img
  src="{{ protocol }}://{{ domain }}/static/images/logo-email.png"
  alt="Loan Manager"
  width="160"
  height="38"
  style="display:block;"
/>
<!-- SVG inline also works for modern clients -->
③ Favicon (base.html <head>)
<link rel="icon" type="image/svg+xml"
      href="{% static 'images/favicon.svg' %}"/>
<link rel="icon" type="image/png" sizes="32x32"
      href="{% static 'images/favicon-32.png' %}"/>
<link rel="apple-touch-icon"
      href="{% static 'images/apple-touch-icon.png' %}"/>
④ settings.py — static dirs
# Make sure this is in settings.py
STATICFILES_DIRS = [
    BASE_DIR / "theme" / "static",
]

# Place logo files at:
# theme/static/images/logo.svg
# theme/static/images/favicon.svg
# theme/static/images/logo-email.png

Step-by-step Integration

Step 01

Save the SVG files

Download the three files from this kit: logo.svg (full wordmark), favicon.svg (mark only), and logo-email.png. Place them all in theme/static/images/.

Step 02

Update base.html navbar

Find the existing logo block in templates/loans/base.html (the SVG coin icon + "Loan Manager" text). Replace it with an <img> tag pointing to {% static 'images/logo.svg' %} with class="h-9 w-auto".

Step 03

Add favicon to <head>

In base.html inside <head>, paste the three <link> tags from the code snippet above. The SVG favicon works in all modern browsers and scales perfectly at any size.

Step 04

Email — use PNG fallback

Email clients (especially Gmail, Outlook) block external SVGs. Export a logo-email.png at 2× resolution (320×76px) from any browser or Inkscape. Use that in the <img> tag inside password_reset_email.html.

Step 05

Collect static

After placing files, run python manage.py collectstatic so the files are copied to staticfiles/ and served by Nginx in production. No server restart needed.

Step 06

Verify in browser

Hard-refresh (Ctrl+Shift+R) and check the navbar, browser tab favicon, and send a test password-reset email. On mobile, the apple-touch-icon shows when users add the site to their home screen.
